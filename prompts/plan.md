# Plan a Task

You are planning work in `aiconfigurator-web`.

Read `docs/assignment-brief.md`, `AGENTS.md`, `README.md`, `ARCHITECTURE.md`, `docs/DESIGN_DECISIONS.md`, `ROADMAP.md`, and `TASKS.md`. Inspect the repository and current Git status. Do not edit application code.

Produce a concise plan containing:

1. The task and its assignment acceptance criteria.
2. The relevant existing files and system boundaries.
3. The proposed files and changes, in implementation order.
4. Tests, container checks, Kubernetes checks, and demo validation.
5. The design-decision questions affected by the task.
6. Risks, assumptions, and decisions that require the user.

Prefer existing patterns. Identify missing project tooling instead of inventing commands. Protect the must-have scope from optional features. If the task involves an architecture choice, hand off to `prompts/architect.md`; do not make that choice in this plan. Stop after presenting the plan unless the user explicitly authorizes implementation.
